01 / The learning loop

Teach the approach.
Measure the contact.

The current baseline learns collision checked approach trajectories. A local controller handles force, dwell time and release. Every completed episode must return home.

  1. 01

    Build the scene

    OpenArm, spring loaded stethoscope, seated body and the approved RGB + depth view.

  2. 02

    Query the expert

    Plan from the current state; retain actual commands, measured motion and contact.

  3. 03

    Export valid windows

    Filter by phase and ownership. Split by body identity before fitting normalization.

  4. 04

    Train official ACT

    Predict 20 actions. Execute the first 10, observe again, then replan.

  5. 05

    Run closed loop

    Score the actual approach, contact, hold, withdrawal and return, beyond action error.

Released ACT baseline

A small, explicit control baseline.

Official LeRobot ACT, 2.66M parameters, no VAE. Two frames of state17 become 34 input features; raw joint targets use one fixed origin per action block.

state17 × 2H20 / E10FP32TRAIN only normalization

The published ACT uses state and target geometry. RGB + depth and Hall are recorded; Hall drives the analytic contact controller. This ACT is not a multimodal VLA, and simulated audio is not used.

04 / Research questions

What does this
preview establish?

The scope matters as much as the score. These answers describe the released evidence and the work that remains.

Is this a clinical or physical robot result?

This page reports Isaac Sim experiments. It does not establish clinical performance or a completed physical robot validation.

Do 8/8 and 0/2 compare the same cohort?

No. The expert passed eight fixed qualification episodes. The ACT pilot was tested on one TRAIN scene and one selection VAL scene. These are separate diagnostic cohorts, not a leaderboard.

What does the ACT policy observe?

Two state17 frames give 34 input features, including state and target geometry. This release does not feed RGB, depth or Hall measurements into ACT. Hall is used by the analytic contact controller.

Why can lower action error still fail?

Offline prediction error does not measure a completed contact task. Both published ACT closed loop cases stopped before contact at posture checks. The full physical gates remain required.

Has Astra executed a simulator episode?

No result is reported. The released prototype constructs a skill request and validates the proposed decision locally. A request is not simulator acceptance or physical success.

What can I reproduce from this release?

The repository includes a reference training runner, array contract, benchmark protocol, evidence summaries and two actual recordings. Training arrays and licensed scene assets must be prepared separately.
