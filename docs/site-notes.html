About this preview

An inspectable
research record.

This static page presents retained Isaac Sim evidence. It reports an expert qualification, an ACT pilot and an Astra interface prototype at different stages of validation.

Evidence and use

The benchmark protocol defines each reported cohort and its limits. The page does not establish clinical performance, generalization to independent held out bodies or a completed physical robot validation.

Training arrays and licensed scene assets are prepared separately. Consult the repository and applicable asset licenses before reproduction.

Website implementation

The demo source includes no contact form, account flow, analytics script or application cookie. The language switch is kept in memory for the current page visit. The font is served with the page rather than requested from a font service.

The website is hosted on GitHub Pages. External links open resources maintained by their respective providers.
