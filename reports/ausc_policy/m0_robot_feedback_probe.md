# M0：偏离状态下，ACT 的局部纠偏仍然很弱

固定同一 TRAIN16 / 2,000 步 ACT、同一原 R4 APPROACH 的 16 个 TRAIN 观测。固定登记目标，逐个关节加 ±0.005 / ±0.02 rad，同时通过相同 FK 重算目标系下 TCP 位姿。阶段、目标 ID 和置信度不变。相对于只改变 q，这避免制造“关节已经变了但 TCP 没变”的不一致输入。

Linux 原生 CPU 完成 480 次确定性推理，其中 448 次扰动、16 次干净输入和 16 次干净重复；无训练更新。没有越过 URDF 边界的样本被排除，干净重复最大差为 0。

| 指标：h5（+250 ms）的原始提案 | ±0.005 rad | ±0.02 rad |
|---|---:|---:|
| 扰动次数 | 224 | 224 |
| 同关节输出变化 / 输入变化，中位数 | 0.99352 | 0.99361 |
| TCP 输出扰动 / 初始 TCP 扰动，中位数 | 0.96515 | 0.96596 |
| TCP 比值第 10–90 百分位 | 0.90553–1.01610 | 0.90425–1.02501 |
| TCP 比值 <1 的次数 | 177 / 224 | 173 / 224 |

两个比值都先分别减去同一观测的干净预测，再计算响应；不是直接用目标误差相除。单纯复制当前 q 的参照值是 1。块相对动作恢复成绝对动作时本来就要加当前 q，因此该结果不能单独证明网络内部采用了某种“复制算法”。更准确的结论是：**该检查点的预测保留了绝大多数输入位姿偏移，学到的块内增量对这些偏移只提供了很弱的局部补偿。**

结合另一项固定 q 的目标平移测试（目标变 5 mm，h5 同向变化约 0.020–0.025 mm），当前证据支持优先修正恢复监督与动作职责，而不是继续增加训练步数或更换 VLA。它不支持“完全忽略目标”或“绝对不会恢复”的断言。

## 范围与下一步

这不是 Isaac 物理实验，没有执行这些动作，也没有给扰动状态提供正确动作标签。仅筛查了 URDF 范围，未证明全部状态都满足姿态或碰撞条件。16 个观测属于同一身体、同一路径，不是 448 个独立受试者或回合。比值 <1 也不是闭环稳定性、接触成功或泛化的证明。没有扰动 RGB、原始深度图或 Hall 电压；不能用于宣称 VLA 有效利用了多模态。

M0 仍未通过。下一步是一个有界恢复数据修复试验：先让专家从当前状态重新求解路径，用原姿态、FCL 和物理检查验证恢复动作；只有真实通过接触、保持与撤离的回合才可成为新标签。在固定模型与训练预算下比较补数据前后，重新跑实际闭环。专家的解析动作及接触前精细对齐须单独记账，不能算成学生的能力。多人体规模化生成和 full VLA 训练仍需等待前置门通过。

另一个独立修复已进代码：粗接触候选与保留起点的精细曲线入口分开检查，后者沿用原 20 µm / 0.0002 rad 条件；不合格时提前拒绝，不添加隐藏的对齐动作。软件测试通过不等于 M0 成功。
