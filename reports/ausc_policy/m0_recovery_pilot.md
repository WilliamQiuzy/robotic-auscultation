# M0：静止状态恢复专家试验

## 问题与范围

ACT 在实际 R4 接近中持续偏离。固定模型的成对输入试验显示，它对目标误差及
一致的关节/TCP 扰动补偿较弱。下一步先验证可提供恢复标签的专家，再考虑补数据。
本试验不训练新模型，不把专家完成计入 M0 状态模型闭环成功。

第一版 oracle 明确只支持 R4、FREE/APPROACH、已脱离人体、实测速度接近零、
连续三个实际指令静止的状态。运动中或 CONTACT/HOLD 状态返回 Abstain，
因此它还不是规格中能支持任意学生状态 DAgger 的完整 oracle。

## 预注册的三组实际试验

独立重建同一批准场景，保持座位、相机、Hall 校准、物理迭代及阈值不变。
每组先真实执行批准的准备路径，再在第三关节加入 0 / +0.02 / −0.02 rad，
实际运动、停车并采集状态；不重置关节、不捏造 RGB-D 或 Hall 观测。
这是人为构造的局部偏离，尚非直接从 ACT 失败轨迹接管，也不表示人体多样性。

查询以实测 q 为规划起点，保留真实指令起点连接，以同一 R4 精确预接触姿态为目标。
复用低肘姿态规划器；新样条每个 240 Hz 指令都重新做 FCL/姿态检查。
速度 ≤0.175 rad/s、加速度 ≤0.5 rad/s²、自由运动 jerk ≤1.5 rad/s³；
自由间隙仍为 3 mm。返回完整专家提案及以当前实测 q 为锚的 H10、50 ms 标签预览。
完整提案在本试验中由专家执行，不冒充 H10/E5 学生在线重查询。

到达后必须通过固定接触曲线的 20 µm / 0.0002 rad 完整位姿入口检查，
再运行原实测解析 L3：Hall/ADC、RGB-D 跟踪及实测关节反馈，4±0.5 N 连续保持 3 s，
原 Hall 5.5 N / PhysX 6 N / 6 mm 硬阈值、接触间隙、撤离及最终回位不变。

## 判定与数据边界

每组记录查询或拒绝原因、实际物理轨迹、所有原始相机/Hall 数据、决策账本，
并执行原机械/低肘审计、独立 ADC/FK/RGB-D 决策重放及实测加速度≤2、jerk≤20检查。
保留所有失败，不改变阈值使其通过。

准备段、恢复段、L3、最终回位有独立角色标记；全部帧目前仍为训练不合格。
即便三组全通过，仍须单独进行原始模态、动作配对、标签导出和恢复数据资格检查。
三组不是专家随机环境≥95%证明；不触发全量 VLA 训练。

配置：`configs/ausc_policy/m0_recovery_pilot.json`。
实际结果以远端新 run 的配置、源码快照、进程退出、case 审计收据为准。
