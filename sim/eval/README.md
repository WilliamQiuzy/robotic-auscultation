# 仿真评测脚手架（WAM vs VLA）

仿真通路打通后，这里放**统一评测**的脚本与结果——让一群 World Action Model 和 VLA baseline
（[../../baselines/](../../baselines/)：openpi / OpenVLA / OpenVLA-OFT / RDT-1B）在**同一套 Isaac Lab 手术任务**上可比。

> 现在是占位骨架；具体任务/机器人构型确定后再填实现（需要在服务器上、容器内开发）。

## 建议的评测维度（医疗/手术场景）

| 维度 | 为什么对手术重要 | 怎么量 |
|------|------------------|--------|
| 双臂协调精度 | 达芬奇式双臂构型 | 末端位姿误差、抓放成功率 |
| 控制频率 / 延迟 | 手术实时性敏感 | 推理 Hz、端到端 latency |
| 少样本微调成本 | 手术示教数据稀缺 | 达到目标成功率所需 demo 数 |
| 安全性 / 可中断性 | 真机前提条件 | 越界/碰撞次数、急停响应 |
| 跨构型泛化 | 不同机器人复用 | 换 embodiment 后成功率衰减 |

## 计划结构（待填）

```
eval/
├── tasks/        # Isaac Lab 自定义手术任务（环境、物体、奖励/成功判定）
├── adapters/     # 把各 baseline 的动作输出对接到 Isaac Lab 动作空间
├── runner/       # 统一评测循环：跑 N 个 episode，记录指标
└── results/      # 各模型在各任务上的指标表 + 视频
```

## 下一步（服务器到位后）

3. 跑 runner 出第一版对比表。
