# 感知提升路线图:2D 抖动 + 3D 稳定性(2026-08-07)

> 承接 [perception_ten_point_audit_2026-08-07.md](perception_ten_point_audit_2026-08-07.md)。4 路深查专攻"如何进一步减少 2D 抖动 / 让 3D 重建更稳",直面用户关切:增强不全面、光照/畸变一变就崩、10 点估不准无法泛化。

## 🔑 最重要的认知纠偏(先看这个)

**你的模型输入是"深度法向量图"(depth→surface normals),不是 RGB。** 三个训练阶段(stage0/1/2)全部在 `normals*127+127` 上训练。

结论:
- **光照变化几乎不可能弄坏这个模型** —— 法向量由深度几何算出,天生光照不变。你担心的"光照一变模型就崩"对**这个**模型基本不成立(是好消息)。
- **那个功能丰富的 `ausc/augment.py`(打光/色相/阴影/高光/sensor_degrade)是 RGB 增强,而且除了一个 QC 可视化脚本外没接入任何生产训练。** 就算接进去,对法向量输入的模型也没用。"增强不全面"属实,但**解法不是加 RGB 增强,而是加深度域增强**。
- **模型的真实软肋 = 深度域**:(1) 深度/法向量噪声;(2) 镜头/焦距畸变;(3) 深度空洞。

## ✅ 今晚已做(已提交,安全)

### 1. 增强的深度噪声 bug 修复 —— 你的 #1 关切,实锤 bug
`rng.gauss(0, 4)`(Python `random.Random.gauss`)返回**一个标量**,加到整张法向量图上 = 全图统一 DC 偏移。**模型从没见过逐像素噪声** —— 而真实 Orbbec 深度的逐像素噪声正是导致它在真机上抖动的原因。三个阶段(stage0:50 / stage1:63 / stage2:97)全中。

修复:新增 `ausc/augment.augment_normal_channel()`,做**逐像素高斯噪声 + 空间相关低频场 + 中性(127)空洞随机丢弃**(模拟真实深度洞),接入全部三阶段。5 个单测钉死(逐像素方差>0、非 DC、空洞中性、均值保持、可复现)。
> **训练专用改动,不影响当前录制;下次重训生效。** 这是让模型"不再一有噪声就崩"的最直接一步。

## 📋 分级路线图(其余)

### A. 免训练快赢(需先在真机 clip 上跑离线 PCK 验证,再上线——不敢在录制前盲改检测器)
| 项 | 收益 | 说明 |
|---|---|---|
| **Flip-TTA 平均**(最高 ROI 免训练) | 独立 2D 抖动 ↓~30%,零延迟 | 置信度那趟**翻转前传已经在跑**,结果被丢了;把它 un-mirror+L/R-swap 后与原估计**逐点平均**(带 2px 守卫,遮挡时回退单趟)。实现要点已写进 detector `_flip_conf` 返回 recovered 坐标 + `_fuse_flip_tta` 纯 numpy 融合。**纯方差缩减,不会更差** |
| **裁剪稳定化**(最高 3D-mm 杠杆) | 共模 3D 从 ~0.73mm→~0.22mm | `geometry.back_square_crop` 每帧用深度掩膜 min/max 重算 bbox→整体闪烁→10 点共模位移;共模以 ~2.2× 穿透星座拟合。改:2/98 分位 + (cx,cy,side) 死区 EMA(大运动时 snap 保持在训练尺度 0.8–1.2 内) |
| **structure_points 稳健拟合** | 中层 3D ~0.3–0.8mm(R5/L5 受益) | 层间距只由最噪的 R5/L5 两端点 linspace 决定;改稳健最小二乘(Huber/Theil-Sen)用全 5 层拟合 |
| **解码 soft-argmax** | R5/L5 边缘 0.3–1px,消除 argmax 翻格跳变 | 当前 sigmoid 质心 + 硬 argmax 会翻格;改局部 softmax 期望(DSNT)+ 边界 reflect-pad |

### B. 需重训的增强/训练(GPU + 你签字)
| 项 | 说明 |
|---|---|
| **深度域增强补全** | 已修的逐像素噪声之外,再加:法向量矢量扰动、弹性形变(呼吸/体态)、**工作距离/焦距随机化**(应对畸变——见下)、更强遮挡 |
| **逐帧真实焦距建法向量** | 推理与训练都用固定 `K=560`(`normals_k560`),与真实焦距不符→法向量随患者距离系统性偏转→侧翼/下方点在呼吸/移动时抖。改真实 `f_eff` 并 stage1/2 各 8ep 轻量重拟合(与 INTER_NEAREST→INTER_LINEAR 一起打包) |
| **确认 DINOv2 冻结策略** | DINOv2 天生鲁棒;若在小数据上全量微调会**毁掉**它自带的鲁棒性→只在训练光照/姿态上过拟合。查是否 LoRA/部分解冻(小数据必须),别全量微调 |

### C. 数据/评估基建(前置——先建,才能安全验证 A/B)
- **一个可复现的离线评估台**:黄衣离线 clip + 留出"扰动/暗/畸变" PCK 集;指标含**每点静态抖动(px)、PCK、3D 星座分解为共模 vs 独立 mm**——否则 A 类改进的收益淹没在 EKF 下限里看不见。**这是上线 A/B 任何一项的前提。**
- **下方点(R5/L5)标注质量核查**:曲面下背难标,标注噪声本身封顶可达稳定性。
- **合成数据补增强缺口**:mesh/USD 管线(test_offline_official_mesh_*)可生成**打光+畸变+穿衣、带完美 GT**的合成背——正好补你说的增强空白,且 GT 无标注噪声。

## 诚实排序:什么真正动指针
1. **裁剪稳定化**(唯一显著动 3D-mm 的单项,~0.5mm,共模主源)——免训练,但需真机验证
2. **逐像素深度噪声**(今晚已修)——你的 #1 关切,治"一有噪声就崩"
3. **真实焦距法向量**(下方/侧翼 1–2mm)——需重训
4. **Flip-TTA**(免费、先做)——主要买 2D 稳定/鲁棒,3D 已近下限
5. 解码/resize——边际,只在打包重训时顺带

**单点最高杠杆 = 裁剪稳定化**(攻共模,2.2× 放大);**你最关心的增强 = 逐像素噪声(已修)**。建议顺序:建离线评估台 → Flip-TTA + 裁剪稳定化(离线 PCK 门控)→ 一次打包重训(焦距 + resize + 深度域增强)。
