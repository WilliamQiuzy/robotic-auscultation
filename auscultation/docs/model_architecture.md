# 模型结构（Model Architecture）

系统 = **VLA 动作策略 + 在其之上额外加的感知模块 + 音频闭环**，共三个模块。各模块输入/输出独立，按下表路由。

## 数据流图

```
   第三人称相机(RGB-D)                          腕部相机(RGB)
        │ RGB                                        │
        ▼                                            │
  ┌──────────────────────┐                          │
  │ ① 感知模块            │                          │
  │ 单图, RGB-only        │                          │
  │ → 稠密IUV → 听诊点    │                          │
  └─────────┬────────────┘                          │
            │ 目标点(2D) + 第三人称深度 → 反投影3D     │
            ▼                                        │
        听诊目标点(3D) ──────────┐                   │
                                 ▼                   ▼
  ┌──────────────────────────────────────────────────────────┐
  │ ② 动作策略 VLA                                            │
  │ 输入: 第三人称图 + 腕部图 + 目标点 + 本体感知 + 力 + 音频 + 语言 │
  │ → 动作                                                    │
  └───────────────────────┬──────────────────────────────────┘
                          ▼ 接触后
              ┌───────────────────────┐
              │ ③ 音频闭环             │
              │ 声音质量 → 落点微调    │
              └───────────────────────┘
```

## ① 感知模块（Perception）

| 项 | 内容 |
|---|---|
| **角色** | 从第三人称视角定位听诊点（前胸 4 / 后背 8），并验证机械臂是否到位 |
| **输入** | 第三人称相机 RGB，`[H×W×3]` uint8（**单视角**） |
| **主干** | 视觉编码器（ViT / CNN）→ 特征图 |
| **输出 1** | 稠密 IUV 图 `[H×W×3]`：逐像素 `(part I∈{0..24,0=背景}, U∈[0,1], V∈[0,1])` |
| **输出 2** | 听诊点：`{点名: (x, y, 置信)}`；区域 `front(4心点)/back(8肺点)/none`；`side_conf` |
| **读出方式** | 预测稠密 IUV → 取与目标顶点 `(I,U,V)` 匹配的像素 = 2D 点；`infer_side`(part2/part1) 定前/后 |
| **训练** | HuMMan 数据集；监督 = 渲染的稠密 IUV；增强（区域居中裁剪/光照/翻转/手臂遮挡）；姿态过滤；betas 体型增强 |
| **部署** | 只跑第三人称相机；深度仅在推理时几何用于 2D→3D 反投影（传感器测量，**不进网络**） |

## ② 动作策略 VLA（Action）

| 项 | 内容 |
|---|---|
| **角色** | 驱动机械臂：逼近→接触→稳到目标力→听诊→按声音探索；腕部近景伺服，第三人称验证到位 |
| **输入** | 第三人称 RGB(+深度) ｜ 腕部 RGB ｜ 感知目标点/区域 ｜ 本体感知(关节状态) ｜ 6 轴力/力矩 ｜ 听诊器音频 ｜ 语言指令 |
| **结构** | 共享多模态 trunk（视觉-语言）+ 力/音频 token 编码器 + 动作 expert 头（flow-matching 或离散 action token） |
| **输出** | 动作块（末端 6D 位姿增量 或 关节目标），按控制频率 `f` 输出（action chunking） |
| **训练** | 主从臂遥操作演示，行为克隆；两视角 + 力 + 音频同步录制 |
| **部署** | 两相机 + 力 + 音频全部在线 |

## ③ 音频闭环（Audio Loop）

| 项 | 内容 |
|---|---|
| **角色** | 接触后用听诊声音精修落点 |
| **输入** | 听诊器音频（接触后 10s）｜ 当前目标点 |
| **结构** | 声音质量评估器 + 局部搜索（贝叶斯优化 / 学习残差策略） |
| **输出** | 落点微调量 / 微动作（在目标点邻域） |
