# 听诊感知 — 后背采集/摆位规范 SOP(v1)

> 目的: 让真实台架采集的图像落在感知模型擅长的输入分布里, 把"免费的精度"先拿到。
> 依据: v3 在实验室 3 张照片上的实测 —— **正对后背时肺点合理; 坐姿前倾/转身时肺点聚到一侧**(`docs/runs/lab_domain/`)。
> 配套: 部署推理自带**姿态质量门**(`infer_overlay.py --gate`), 不合规会提示重新摆位。

## 1. 受试者摆位(关键)
- **坐直**, 脊柱竖直, **不前倾、不转身、不侧弯**。
- **后背正对相机**(肩线与相机像平面平行; 两侧肩对称入画)。
- **双臂自然垂于体侧或放腿上**, 不抱胸、不抬臂遮挡后背。
- 头部自然朝前(可入画), 不大幅低头/侧头。
- 着合身上衣即可(穿衣 OK), 避免过厚外套/大面积褶皱堆叠遮挡背部轮廓。

## 2. 相机/取景
- **第三人称机位**: 正对后背, 镜头略高于肩(俯角 ~5–15°), 不要大俯/大仰。
- **竖构图(3:4)**, 人居中。
- **取景距离**: 让**躯干(肩→腰)占画面竖向 ~55–70%**, 头在顶部 ~15–20%, 双手在底部入画。
  - 太远(人很小) / 太近(只剩局部) 都会掉点 → 以"躯干填中部"为准。
- 镜头与受试者基本水平正对, 避免大角度斜拍。

## 3. 背景/光照
- 背景尽量**干净、低杂物**(当前蓝色手术铺巾 OK; 模型对背景较鲁棒, 但越干净越稳)。
- **均匀室内光**, 避免单侧强光/硬阴影/背光(背光会让后背欠曝, UV 回归变差)。
- 避免镜面反光直打后背。

## 4. 采集流程(每位受试者)
1. 按 §1 摆位 → 按 §2 取景。
2. 拍 1 张 → 跑 `infer_overlay.py --gate`(见 §5)。
3. 门**PASS** → 记录; 门**REPOSITION** → 按提示纠正(坐直/正对/调距离)后重拍。
4. 同一姿势可连拍 2–3 张备用。

> 注: §1–3 是**一次性台架/协议设置**(相机机位、背景、让受试者后背正对而坐), 不是每张图的人工操作。
> 运行时**全自动、无人在回路**: 实验室只给类似那 3 张的原始图, 下面的置信度+自动选帧全自动跑。

## 5. 运行时全自动置信度 + 自动选帧(部署侧, 已实现)
`python ausc/training/infer_overlay.py --ckpt <best.pt> --imgs <图/目录> --region back --gate 1 --tta 1.0,1.14,1.27`
- 对每帧自动算 **置信度 conf∈[0,1]**(后背占比/肺点横向展开/左右平衡/纵向覆盖/点数加权), 输出 flags(low_back_frac/points_collapsed/LR_imbalance/missing_points)。
- 多帧时**自动挑 conf 最高的一帧**喂机械臂(`[auto-select]`)。
- conf 作机器信号: 低于阈值 → 机械臂更保守 / 换下一帧 / 触发重拍, **无需人工**。
- 实测: 3 张实验室照片 conf=1.0、无 flag(均合规)。
