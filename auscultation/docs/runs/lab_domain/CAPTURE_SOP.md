# 听诊感知 — 后背采集/摆位规范 SOP(v1)

> 目的: 让真实台架采集的图像落在感知模型擅长的输入分布里, 把"免费的精度"先拿到。
> 依据: v3 在实验室 3 张照片上的实测 —— **正对后背时肺点合理; 坐姿前倾/转身时肺点聚到一侧**(`docs/runs/lab_domain/`)。
> 配套: 部署推理自带**姿态质量门**(`infer_overlay.py --gate`), 不合规会提示重新摆位。

## 1. 受试者摆位(关键)
- **坐直**, 脊柱竖直, **不前倾、不转身、不侧弯**。
- **后背正对相机**(肩线与相机像平面平行; 两侧肩对称入画)。
- **双臂自然垂于体侧或放腿上**, 不抱胸、不抬臂遮挡后背。
- 头部自然朝前(可入画), 不大幅低头/侧头。
- 着合身上衣即可(穿衣 OK), 避免过厚外套/大面积褶皱堆叠遮挡背部轮廓。

## 2. 相机/取景
- **第三人称机位**: 正对后背, 镜头略高于肩(俯角 ~5–15°), 不要大俯/大仰。
- **竖构图(3:4)**, 人居中。
- **取景距离**: 让**躯干(肩→腰)占画面竖向 ~55–70%**, 头在顶部 ~15–20%, 双手在底部入画。
  - 太远(人很小) / 太近(只剩局部) 都会掉点 → 以"躯干填中部"为准。
- 镜头与受试者基本水平正对, 避免大角度斜拍。

## 3. 背景/光照
- 背景尽量**干净、低杂物**(当前蓝色手术铺巾 OK; 模型对背景较鲁棒, 但越干净越稳)。
- **均匀室内光**, 避免单侧强光/硬阴影/背光(背光会让后背欠曝, UV 回归变差)。
- 避免镜面反光直打后背。

## 4. 采集流程(每位受试者)
1. 按 §1 摆位 → 按 §2 取景。
2. 拍 1 张 → 跑 `infer_overlay.py --gate`(见 §5)。
3. 门**PASS** → 记录; 门**REPOSITION** → 按提示纠正(坐直/正对/调距离)后重拍。
4. 同一姿势可连拍 2–3 张备用。

## 5. 自动质量门(部署侧, 已实现)
`python ausc/training/infer_overlay.py --ckpt <best.pt> --imgs <图> --region back --gate 1 --tta 1.0,1.14,1.27`
判定依据(任一不达标 → REPOSITION + 原因):
- **后背占比** back_px/前景 ≥ 阈值(确认是后背、未大幅转身)。
- **肺点横向展开** x-range/躯干宽 ≥ 阈值(双侧肺野张开, 非聚成一条)。
- **左右平衡** L1–4 与 R1–4 分居中线两侧(转身会塌向一侧)。
- **纵向覆盖** 上肺→下肺 y 跨度合理。

## 6. (留给标注环节, 见 §③数据采集)
采集时若能顺带人工标 8 个肺点(触诊定位/贴标记点), 即得真实验证集 + 微调集 —— 另见数据采集 SOP。
